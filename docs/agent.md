## 4. Coding & Architecture Rules

*   **Framework**: Next.js 16 (App Router) using React 19 and TypeScript.
*   **Styling**: Vanilla CSS in Tailwind CSS v4.
*   **Type Safety**: Strict TypeScript, zero `any` usage. All components, interfaces, and event structures must be typed.
*   **Rendering**: React Server Components (RSC) by default; `"use client"` only where stateful interactions (forms, animations, modals) exist.
*   **Performance**: LCP under 1.5s, zero cumulative layout shift (CLS = 0.0), fast mobile rendering.
